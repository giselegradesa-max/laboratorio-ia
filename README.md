# 🚀 Projeto: Sistema de Cadastro - Agentes de IA

Projeto desenvolvido como parte da minha transição de carreira para a área de Tecnologia, Automação e IA.

## 📌 Sobre o Projeto
Este projeto foi construído utilizando um **Time de Agentes de IA** para mapear a solução da especificação até o código funcional.

## 🛠️ Estrutura do Projeto
- `PRD.md`: Requisitos do Produto e Histórias de Usuário (Product Owner)
- `ADR.md`: Decisões de Arquitetura e Stack Tecnológica (Arquiteto de Software)
- `DESIGN.md`: Fluxo de Telas e Interface (UX/UI Designer)
- `index.html`: Código-fonte da aplicação (Desenvolvedor Fullstack)

## 🌐 Tecnologias Utilizadas
- HTML5 / CSS3 / JavaScript
- GitHub Codespaces (Ambiente 100% em Nuvem)
- Engenharia de Prompts e Agentes de IA
